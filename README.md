# POO_JAD_PROTOCOLO_COLABORATIVO_UNIDAD_1_TALLER_2

Taller 2: El uso de this en Java.

Cada ejemplo y ejercicio está en su propia carpeta y usa un paquete diferente.
Así los varios Main.java pueden convivir en un mismo proyecto sin producir
errores de clase duplicada.

Los archivos PersonaIncorrecta.java.txt conservan los códigos incorrectos que
la guía pide intentar, pero como texto no interfieren con la compilación.

Para ejecutar: abre un Main.java y selecciona Run 'Main.main()'.
